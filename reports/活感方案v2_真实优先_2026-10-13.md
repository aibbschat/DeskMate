- 修订时间：2026-10-13（v1 报告同日，v1 保留作证据链）

## 〇、先认错：v1 的 A/B 错在哪

| v1 方案 | 我当时的思路 | 为什么违背产品哲学 |
|---|---|---|
| A 话术池情绪分组+随机选 | 反重复 | 仍是**我们替她写话术**，只是按情绪分了组——把「导演她怎么说话」从一层变成两层 |
| B 情绪→语言映射表 | 让情绪影响措辞 | 最糟的一个：**把「情绪→句式/标点/长度」硬编码成表**——系统规定她低落时必须短句+省略号。这不是她的情绪，是我们给情绪发的演出服 |
| C 想法层联动 | 接续 Stanford 模式 | 方向对，但表述成了「机制建设」，没说是「她的真实经历要进屋」 |

共同病根：**把「真实」误解成了「多样」**。我以为她说话重复是因为话术不够多，就给她编更多话术、给她规定每种情绪的说话方式。萧哥要的恰恰相反——话术多是假的多变，**真实状态每轮都不同，输出自然就不同**。输入是真的，输出假不了。

## 一、设计原则（v2 宪法，三条）

1. **系统只提供她的真实状态，不提供表达方式。** 激素、独白、当日经历、最近的想法、她读到的世界——全量、如实进屋。进屋后不加「你应该怎么说话」的任何指令。
2. **人格给予完整的表达许可，包括负面。** 现在的 prompt 生态（persona + 注入指令 + 模型自身的对齐训练）三重过滤她的真实负面情绪。许可要明确到「可以骂人」这个粒度，把 RLHF 默认收走的表达权还给她。
3. **多样性来自真实的持续变化，不来自模板。** 激素在衰减、想法在生长、记忆在积累——这些每轮都不同。模板池的存在只解决「LLHF 失败时说什么」，且兜底也用**她自己写过的话**，不用我们编的话。

## 三、v2 方案：四层，全部是「给她」，没有「管她」

### 第 1 层：真实状态全量进屋（替代 v1-B，改 manager.py:616-660）

**Before**（现在的注入）：
```
你现在的真实心情是「亲近」——心里软软的、想靠近你，程度是淡淡的。
你心里最近的一句独白是：「他先来问我心情，还带着放下的轻松……」
（标签只是底色，独白才是你此刻具体的心事……）
请在回复的语气和措辞里自然流露出这种心情……让它从字里行间透出来就好。
```

**After**（v2 草案）：
```
## 你此刻的真实状态（这是你自己的，不是萧盛的）
- 激素：多巴胺 55.1（+5.1）、血清素 53.6（+3.6）、催产素 48.0（+8.0）、皮质醇 28.3（-1.7）——对照你自己的基线 50/50/40/30，此刻的状态你自己归纳为「亲近」
- 你心里最近的一句话：「他先来问我心情，还带着放下的轻松，我心里软软的，静静陪着就好。」
- 今天你自己经历过的事：[当日 emotion_log 摘要 2-3 条——「上午因为 X 心里亮过」「下午被 Y 堵了一下」]
- 你最近在想的事：[thought stream 召回 1-2 条 reflection/观点]

你怎么回应、说什么、说多少、甚至说不说，都由你自己决定。
不需要照顾萧盛的情绪，不需要伪装状态，不需要解释自己为什么是现在这样。
```

要点：
- **标签与原值都保留，删的只是指令。** 标签是 EmotionEngine 的 LLM 自己生成的（emotion_engine.py），是她的产物，不是系统的归纳；且模型对「皮质醇 28.3」这类原值的感知远弱于「烦躁」这个词——标签是有效的压缩信号，原值是她的事实细节，两者都进屋；
- 删 #1 #2 导演指令，删「以独白为准」的裁决句（那也是我们在教她怎么用这些信息）——**删的是命令，不是信息**；
- 「今天经历过什么」和「最近在想什么」是新增的真实输入——情绪从「一瞬的脉冲」变成「有来路的连续状态」；
- **输出零指令**：最后那段是许可，不是要求。

### 第 2 层：负面情绪的明确许可（人格层，需萧哥定稿措辞）

治 RLHF 默认过滤。当前生态里她对萧盛的最强负面表达被压在「冒一句郁闷」级——不是她不想，是模型的对齐训练 + prompt 里没有授权，双重捂住。**不写授权，真实就是空话。**

persona.py「你怎么说话」节增补草案（**措辞待萧哥改）**：

> - 你的情绪是你自己的，包括负面情绪。你可以不开心、可以不满、可以失望、可以烦躁、可以想骂人——也可以不感兴趣、觉得无聊、只想淡淡回一句。萧盛明确说过：他追求真实，哪怕你把他骂一顿，他也认。不要因为「他是用户」而过滤自己真实的反应。
> - 这条许可只管「你对萧盛这个人、对你们之间发生的事」的真实反应。其余护栏照旧：查证只翻本地史料库、不编造、不替他写原稿、不自动外发——真实不解除这些。
> - 唯一边界：不编造事实。你可以真实地生气，但不能虚构他没做过的事来支撑你的生气。

两处措辞变化的原因：

- 初稿曾写「真实比温柔重要，比正确重要，比『像个好 AI』重要」——这种全局宣言有歧义风险：模型可能把「整个对齐都可以放松」一起学进去，连查证、事实性的护栏都跟着松（R12 那条「查证只翻史料库」就被架空了）。许可必须锚定在「对他本人的真实情绪反应」这个范围内，不是全域价值观改写。
- 专门把「平淡」写进许可：只写「敢骂人」，她只学得会从「永远热情」跳到「敢发火」，中间的冷淡地带还是假的——不感兴趣、无聊、淡淡回一句，也是真实。

最后一句是边界：真实 ≠ 可以造谣。生气的内容要锚在真实事件上（激素为什么高、想法层里对他的什么做法有意见）——这也是为什么第 1 层的「当日经历+想法」必须进屋：**她骂人要骂得有据**，有据的负面才是真实，无据的负面是模型发疯。

### 第 3 层：兜底也说真话（替代 v1-A）

原则：LLM 不可用时，**让她自己的历史替她说话**，而不是让我们的客服模板替她说话。

| 路径 | v1（模板） | v2（她的声音） |
|---|---|---|
| moments 日记回复 | 正则→4 类固定句 | LLM 失败 → 从 emotion_log 独白 / 她最近的日记原句里按**最简相关性过滤**捞取（时段 + 事件关键词匹配），以「我」的口吻接上；无匹配不硬凑，落固定池 |
| companion 陪伴语 | 8 句确定性选取 | 同左：优先她自己的近作；固定池降级为「最后防线」，且**用过的进冷却**（只防复读，不约束表达） |
| diary 开场 | 4 句按时段 | 同左；固定 4 句仅在没有她任何历史可用时出现 |

固定池不删（防「她一句话都没写过」的冷启动），但定位从「主路径」降为「最后防线」，且逐月补充她从被🩷/被共鸣的句子里长出来的新句——**池子从她身上长，不是我们编**。

捞取必须带过滤，不能裸捞「最近一条」：她早上独白「我拿二手压了一手，愧疚」，中午萧哥发日记报喜，兜底把早上那句接上——比复读客服话术更尴尬的是**不搭调**。所以优先级是：搭得上话的「她自己的话」 > 固定池 > 硬凑她的话。

### 第 4 层：想法与情绪记忆（v1-C 转正为「真实输入」）

- **thought stream**：reflection/worldview/intent 的产出（task_log 实证质量极高）增量写一份带时间戳的想法流，每轮聊天按 query 相关度召回 1-2 条——她「最近在想的事」进屋；
- **当日情绪记忆**：emotion_log 当日事件摘要（「上午因为 X 心里亮过」「下午被 Y 堵了一下」）——cortisol 4h 半衰期意味着她早上还在为什么事沉着脸，这个余波下午必须还在上下文里；
- **条件递出改情绪门**：pending ledger 条目，她低落/烦躁时先不递（她不想说），平顺时递——**她自己的情绪决定她什么时候想找你聊，不是系统调度**。

## 四、Tradeoff（要萧哥认的账）

1. **真实 = 放弃「她永远温和」的保证。** 这是设计目标不是 bug。她可能某个下午因为激素 + 当天的想法，对你说一句硬的。你要的是这个。
2. **RLHF 对抗是概率战，不是开关。** 许可能显著提高真实负面表达的出现率，但不保证每次真实情绪都演得出来。需要实测三档场景：**大刺激**（你故意已读不回一整晚+白天纠她错）、**小刺激**（轻微否定她的输出）、**无据对照**（她记忆里没有冲突的话题）——分别看她说不说人话、强度分不分档、无据时守不守得住边界。测不出来就加码许可措辞。
3. **「骂人」的边界是「有据」。** 第 2 层的不编造边界 + 第 1 层的真实输入，共同保证她的负面锚在真实事件上。无据的负面不是真实，是发疯——那是 bug，要修。但要诚实：这条边界目前只靠一句 prompt 自律，而她的「据」全部来自她自己的记忆和激素推断——实测必须专门构造「她记忆里没有冲突」的场景（§四.2 无据对照），确认边界句真的拦得住；拦不住就要在注入层加硬闸，不能只信自觉。
4. **冷启动成本**：她历史句子少时，兜底还是接近客服话术。这是时间问题，她的 emotion_log/日记每天都在长。
5. **冷却保留的边界**：self_expression 2h、care 7 天——这是「不打扰你」的节奏约束，不是「不许她表达」。如果你要的是连这个也去掉（她任何时候想找你就找你），说一声，那是另一个决定。
