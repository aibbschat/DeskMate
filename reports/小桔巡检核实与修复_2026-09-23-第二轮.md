## 2. 🔴 红线（P2-3 神圣稿件）：两大漏洞与修复

### 2.1 漏洞实锤

| 攻击姿势 | 结果 |
|---|---|
| `ingest` 直传神圣路径 | `{'ingested': 1}` —— **神圣正文已写入 deskmate.db** |
| `scan` 经 symlink | 扫出 `dirlink/ch1.md`，excerpt 含正文 |

根因：
1. **ingest 侧零守卫** —— `local_intake.py` 的 `_is_sacred` 只在 `_walk`（scan 侧，原 114/118 行）
   被调用；`build_facts`(181) → `_excerpt` 直接读盘、`ingest_files`(195) 直接吃 `paths` 参数，
   **不查神圣、不查扩展名、不 resolve**；端点还允许任意 `paths`。
2. **symlink 绕过** —— 判定只看**字面路径** `parts`；配置目录里 `dirlink -> ~/国子监秘闻录`
   这个名字本身不含敏感词，未 `resolve()` 就被 follow 进去。`private_store.py` 同病。

### 2.2 根治办法：收敛成单一事实源

新增 **`deskmate/sacred_paths.py`** 作为唯一实现（此前两份副本 **都已漏防**，副本必然再漂移）：

- `is_sacred(path)`：字面路径 + `resolve()` 后的真实路径**双重判定**；
- `guarded_file(path, allowed_exts)`：外部可控路径抵达文件内容的**最后一道门**，
  强制 resolve + 神圣否决 + 扩展名白名单；
- `guarded_dir_entry(path)`：遍历时按生成目录模型判定。

`local_intake.py` 与 `private_store.py` 全部改为调用它（后者 `_is_sacred` 直接委托，
一行改动让 `_walk` / `scan_sources` / `ingest_files` 三个调用点同时获得防护）。

**设计取舍**：允许指向非神圣位置的**合法 symlink**（用户拿软链整理笔记是正当用法），
只把"解析后落在神圣路径内"钉死成一票否决。

### 2.3 实测证据（`/tmp/verify_sacred_guard.py` + 新增 10 例回归）

```
1) scan 含 symlink        → 候选仅 ['/notes/ok.md']          PASS
2) ingest 直传神圣路径     → {'ingested': 0, 'skipped': 1}   PASS
3) ingest 经 symlink ×2   → {'ingested': 0, 'skipped': 2}   PASS
4) private_store 两姿势    → ingested 0                      PASS
5) private_store scan      → 无 dirlink/filelink             PASS
6) 正常文件仍可用           → ingested 1（未误伤）             PASS
```

## 5. 已知残余缺口（诚实列出，未擅自修）

1. **遗忘不级联到语义通道**：`external_items` 表无 `fp`、只有 `content_hash`，与
   `learned_history` 的指纹算法不同 ⇒ **没有可靠的跨表关联键**。若用文本模糊匹配做级联
   会误伤真实记忆。**根治需要**：记忆来源落 `source_ref`（记录由哪条 external item 派生），
   遗忘时按它精确级联。待萧哥拍板后再动。
2. **P1-4 执行器缺失**：提议卡「执行」对写文件/发消息/删除尚无真实执行器。
3. **P1-4 可见性**：提议卡只在 DeskHome 且 idle 渲染，聊天中不可见；AI 圈发帖有意标 low（设计）。
4. **物理删除条目在历史快照中不出现**：`profile_as_of` 遍历当前条目，已遗忘的不入历史快照。
   这与"遗忘应彻底"一致，维持现状。
5. 我方自检额外发现（**不在巡检清单内**，已一并记录）：
   - `build_facts` 摘要若含 `《书名》` 会触发实体抽取 → 矛盾取代误伤真实书稿记忆；
     当前实现刻意不用《》，**已确认合规**，但属脆弱约定。
   - 神圣清单另有两份副本（`deskmate/memory/after_action.py:_SACRED_MARKERS`、
     `deskmate/roundtable/web.py:_SACRED_MARKERS`），语义是"文本内容过滤"而非路径，
     暂不动，但**存在漂移风险**。
