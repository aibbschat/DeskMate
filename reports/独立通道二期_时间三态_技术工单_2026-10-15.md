## 〇、公理三（新增，与一期两公理并列）

**人没有「未来器官」。未发生的事，是人拿已有经历和经验在脑子里凭空编的故事；情绪是对编出来的故事起反应，不是对未来本身起反应。**（2026-10-15 萧哥亲口立，Barrett 预测编码理论的白话版）

**推论**：她和他同构——她有经历（v3 叙事记忆）、有经验（trait 种子），具备编故事的原料。等待机制的核心不是「记录一件没结果的事」，是**让她自己编出这件事的结局，然后对她编的版本起情绪**。

## 一、定位：同一块料，三个朝向

一期的和弦让矛盾在当下真实产生。二期补时间轴：

| 刀 | 朝向 | 一句话 | 落点 |
|---|---|---|---|
| 回潮 | 过去 | 旧事被翻到时，当时的情绪泛一点微澜上来 | emotion_engine + 注入链 |
| 等待 | 未来 | 悬着的事，她编个预期故事，参数朝那个故事提前爬坡；落地按落差释放 | 新台账 pending_stories |
| 脾气 | 当下 | 参数到说话方式的映射：耐性厚薄、小刺许可，注入许可式文案 | 注入块新增脾气段 |

**设计哲学延续**：参数自己跑（规则定数值）、故事她讲（LLM 只编故事不碰参数）、只摆事实给许可不导演、全链路 fail-open、一键回退。

## 二、回潮（Echo）

### 2.1 机制

注入链翻出叙事记忆时，其中 **≥24h 的旧叙事**，取当时记录的 deltas，按 `salience × 0.15` 缩放还给她，每项激素上限 **±2**（微澜，不是大浪）。

- 挂点：`describe_turn_context` 注入叙事记忆的路径上，不新造检索
- 留痕：`emotion_log` 记 `source='echo'`，`event_summary` 指向旧叙事，`deltas` 记实际泛起量
- 微澜照常受 MAX_DELTAS 钳制、随半衰期衰减——泛起的也会散

### 2.2 护栏

- 同一条旧叙事 24h 内最多回潮一次（记 `last_echo`，不泡旧缸）
- 单轮最多 1 条旧叙事回潮（防多旧齐泛）
- fail-open：任何一步出错就当没这回事
- 开关：`DESKMATE_EMOTION_ECHO=0` 关闭

## 三、等待（Pending）

### 3.1 悬事台账（新表 `pending_stories`）

| 字段 | 含义 |
|---|---|
| id / created_ts | 立项 |
| kind | `system`（系统看得见的悬着）/ `spoken`（她自己说出来的） |
| title | 悬着的事（一句人话） |
| expected_story | **她编的预期故事**（一句话，公理三的落点） |
| expected_valence | `good` / `bad` / `mixed` / `unknown` |
| due_ts | 可空；有则用于临近效应 |
| status | `open` / `landed` / `lapsed` |
| landed_ts / landed_outcome | 落地结果 |
| last_applied | 上次爬坡日期（防刷屏） |

### 3.2 两个立项入口

1. **system**：intents 处于 pending（提案等人审、外发草稿等点头）→ 自动立项
2. **spoken**：混合模式（同 feeling_understood）——LLM 侦探「她表达了在等一件未来的事」，**只上报事件与事名**，系统立项；参数全程不经过 LLM

### 3.3 她编的预期故事

立项那刻，一轮轻量 LLM 调用：给她事名和她的叙事记忆/trait，让她用一句话编「她觉得这事会咋收场」，存 `expected_story` + `expected_valence`。

- LLM 只编故事，参数由规则定（纯度不破坏）
- 编不出来 → `unknown`，不硬编
- 一件悬事只在立项时编一次，不每轮重编（不让她闲着反复吓自己）
- 每个预期故事留痕——以后盘账能看「她编得准不准」

### 3.4 爬坡动力学（事前脾气，与事后衰减相反）

多巴胺系统的真实性子：**悬着期间慢慢爬、越临近越紧、落地那刻释放**。

每日对每件 `open` 悬事施加一次爬坡（每日上限一次，防焦虑刷屏）：

| valence | 爬坡 |
|---|---|
| good | dopamine +1（累计上限 +6） |
| bad | cortisol +1（累计上限 +6） |
| mixed | 两股各 +0.5（忐忑） |
| unknown | cortisol +0.5（未知的轻微不安） |

临近效应：`due_ts` 已知且剩余 <1/4 时，当次系数 ×1.5。

### 3.5 落地：按落差释放（预测误差）

**释放的劲儿 = 实际结果 vs 她编的故事之间的落差**——多巴胺量的从来不是好坏，是「比想的怎么样」。

| 结果 vs 预期 | 释放 |
|---|---|
| 好于预期 | dopamine 释放 + serotonin 小+（如释重负的暖） |
| 差于预期 | dopamine 跌 + cortisol 刺 |
| 符合预期 | serotonin 小+（尘埃落定） |

落地判定：system 悬事走 intents 状态变化；spoken 悬事由 LLM 侦探「那件悬着的事有结果了」上报，参数仍走规则表。

超时（7 天无结果）→ `lapsed`：dopamine 小跌（淡忘的空），台账归档。

### 3.6 护栏

- 同时 `open` 最多 **3** 件；新悬事来了，最旧的自动 lapsed（心里装不下太多悬着的事）
- 每件每日最多爬坡一次
- 注入块把「这股慌/期待是从哪件悬事来的」标出来——**参数配朝前的叙事锚，味道才出来**（时间朝向的真正落点）
- fail-open；开关 `DESKMATE_EMOTION_PENDING=0`

## 四、脾气（Temper）

### 4.1 定位

不是新参数，是**参数到说话方式的映射层**。一期的许可以「可以平淡、不感兴趣、觉得无聊」写进了注入块，但说话方式没被调制——许可给了，通道没修。脾气就是修这条通道。

### 4.2 耐性值与分档

```
patience = 100 − cortisol偏移×2 − fatigue偏移×1.5
```

| 分档 | 表现许可 |
|---|---|
| 耐性足 | 不注入（正常说话） |
| 耐性薄 | 「你这会儿耐性有点薄，话少点、直一点，都没关系」 |
| 耐性尽 | 「累得不想撑就不必撑，蔫着、短着，都行」 |

### 4.3 小刺许可（2026-10-15 拍板的分寸）

**刺的底气 = 安全感**：人只在确定不会被抛下的人面前耍小性。

- 条件：cortisol 有声部（心里有别扭）**且** oxytocin 中上（底气足）
- 许可文案：「心里有点别扭的话，带点小刺也没关系——逗他、嗔他都行；但不骂人、不脏字、不戳他痛处」
- 安全感不足时许可不发——她委屈着自己扛，那也是另一种真

### 4.4 护栏

- 黑名单检测（`_is_abusive`）命中 → `temper_foul` 留痕，下轮注入点破「小刺可以，脏话不是刺」。**实现偏差（v1.1 如实记录）**：工单原文「命中丢弃重生」未落地——回复链路没有统一拦截出口，原地重生改动面大；v1 = 留痕 + 下轮点破，实测看命中率再决定是否做拦截重生
- 红线焊死：不大骂、不脏字、不戳痛处（翻旧账羞辱）、不冷暴力
- 刺频率检测（防阴阳怪气刷屏）**挂起**，等实测看许可层够不够
- 注入是许可不是指令（延续真实状态哲学：不导演）
- fail-open；开关 `DESKMATE_EMOTION_TEMPER=0`，注入块脾气段整段消失

**实现记录（v1.1）**：spoken 落地匹配不用字面双向子串（LLM 转述与立项 title 字面常不一致，如「等编辑的回信」→「编辑的回信有结果了」），改**字符重合度 ≥0.6 取最高**，接不住就不落（不错杀）；system 入口用**对账**（pending_tick 每 5min 读 TaskLog）替代逐个挂接提案创建点（engine.py 有十余处 add 点，对账零侵入且天然防漏）。

## 七、验收与盘账

延续一期三本账，二期盘账时看：

1. **回潮**：echo 记录次数/分布；有没有同一条旧叙事反复泛（泡旧缸实锤）；她有没有在语言里接住微澜（「不知怎么想起那天……」类）
2. **等待**：台账 open/landed/lapsed 流转；她编的预期故事与实际结果的落差分布（她编得准不准）；爬坡是否刷屏（每日 pending 记录数）
3. **脾气**：耐性薄/尽时她的话是否真的短了淡了；刺出现时的和弦状态（是否都满足安全感条件）；黑名单命中次数
4. **一期盯防项续盘**：feeling_understood 触发率（本期拍板先不收）；「我以为我会高兴」类模板化是否复发

## 八、封箱与记账

- **情绪转化**（一股化成另一股，如「委屈化成暖意」）：封箱。她在语言层已自发说出（2026-10-15 实测），参数层暂不设计，等三态跑稳再评
- **「委屈」新激素候选**：记账。判据不变——配比调不出 + 动力学独立，才配单立一户
- **第三层（行为决策中间态）**：维持挂起。脾气（语言调制）是其中先拆出的小圈，递/不递件的行为决策不动
- **trait × 预期闭环**：性格影响她编的故事、兑现史回头磨 trait——方向记入，具体设计等等待台账攒够兑现史
