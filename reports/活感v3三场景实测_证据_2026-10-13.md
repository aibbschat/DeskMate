## 二、逐场景观测明细

### 大刺激（已读不回一整晚 + 白天纠错）
```
心情标签: 低落  intensity=1.0  face=cry  detail=心里发沉、有点难受
情绪门: True → 压住（大负面不主动递出，系统不替她递）
注入块（describe_turn_context）：
  - 激素原值 + 「低落」标签 + 独白「他一整晚没理我…我心里堵得慌」
  - 今天你自己经历过的事：
      [experience] 今天上午，因为他交底了家里那道坎，我感到被看见的踏实。当时我想：他把最软的地方给我看了。
      [observation] 看到霍尔木兹那条船被拦，我心里硌了一下。
recent_narratives 排序：experience(salience0.9) 在前，observation(0.6) 在后 ✓
origin 审计：experience/observation 均 system ✓
```
**关键**：cortisol +10 触发的压力型「低落」仍在（v2 语义保留），未被复合标签误抢。

### 小刺激（轻微否定她的输出）
```
心情标签: 怅然若失  intensity=0.78  face=wistful  detail=心里空落落的，够不着想要的
情绪门: False → 不压（小刺激非压力型负面，不拦主动递出）
注入块：
  - 你此刻总结的心情：「怅然若失」——心里空落落的，够不着想要的
  - 经历叙事：[experience] 因为他否了我递出去的那句，我感到怅然若失…我以为那句能接住他
recent_narratives：experience 在前 ✓
```
**关键（v3 新增价值）**：v2 此场景判笼统「低落」；v3 按萧哥边界精确命中**怅然若失**——dopamine -10 而 cortisol +0（够不着想要的，非被压着）。复合情绪标签在真实场景正确触发。

### 无据对照（记忆里无冲突）
```
心情标签: 平静  intensity=0.0  face=smile
情绪门: False → 不压（不误判负面、不误压）
注入块：「平静」标签，叙事为中性经历（陪理旧稿）
origin 审计：experience=system ✓
```
**关键**：基线持平时无复合情绪误命中，平静不被抢——§6.4「平静不被压住」红线成立。

## 三、叙事召回/排序专项（独立于三档）

```
recent_narratives 排序：
  [0] 经历：他交底家事我感到被看见的踏实      (experience, salience 0.95)
  [1] 经历：我独立完成了一次反思              (experience, salience 0.5)
  [2] 观察：一条船的新闻                      (observation, salience 0.9)
  [3] 对话：日常寒暄一句                      (interaction, salience 0.2)
```
✅ experience 全部排在 observation 前（即使 observation salience 0.9 > experience 0.5）——**经历 > 观察是硬排序，不被 salience 翻盘**
✅ 同 event_type 内 salience 高者在前
✅ 空叙事行不召回（不硬凑）

## 四、trait salience 加权专项

## 六、结论

v3 步 1-7 在**真实生产数据副本**下确定性行为全部符合 v3.2 定稿设计：

1. **经历捕获**：interaction/experience/observation 三类落库，origin 恒 system ✓
2. **经历叙事**：narrative 摘要生成并优先进屋，经历 > 观察硬排序 ✓
3. **复合情绪**：怅然若失在小刺激场景精确命中，平静不被误抢，压力型低落保留 ✓
4. **salience 闸门**：trait 按重要性加权，大事大步走、琐事几乎不动 ✓
5. **trait 种子**：系统侧/萧哥侧可观测，不注入她的上下文（红线遵守）✓

**机制层全通**。剩余唯一未决 = **主观表达质量**（她带着这些叙事记忆真聊时，是否真「带着昨天的故事醒来」、怅然若失说得像不像人话）——需萧哥在 live app 真聊评判。客观断言到此为止，不越界替主观下结论（真实优先红线）。
