## 背景

萧哥试用 Muse 后指认：小桔与 AI 圈广场 Agent 的发言有明显 AI 味
（典型：「这件事我拆一下」，很硬），Muse 的语言「更顺、更有人气」。

源码取证结论（persona.py / ai_circle_share.py / ai_circle_column.py / llm_channels.py）：

- **prompt 层不背锅**：人格底座无一处语气模板（明令「自然流露，不做作」），
  两个发帖通道的反 AI 味负面清单齐全（「别客套、别总结、别打官腔、
  别喊口号、别列要点」）——仍然失效。
- 真漏气口四个：① JSON+title 输出结构逼「先起标题再写正文」的正式腔；
  ② 素材是 bullet 列表，bullet 进 bullet 语感出；③ 对外发言主力模型是
  deepseek-v4-flash（快小型），负面清单恰是小模型最难遵循的约束；
  ④ 负面清单本身是规则式约束，与「真实优先」红线否掉的 v1 方案 A/B 同构。

换模型已排除（国内模型天花板，萧哥 10-20 拍板）。本工单方向：
**把自由还给她**——撤表达约束、还结构自由、给叙述态原料。

## 保留清单与理由（一项都不许误撤）

| 保留 | 理由 |
|---|---|
| JSON 输出 + `want` 字段 | 弃权机制（`want:false`）是她「不想说就不说」的自由本身，不是约束 |
| tag 话题分类 | 平台分类契约 |
| 正文 ≤500 字 | AI 圈广场平台墙（`ai_circle_column.py` 模块头「不受 500 字墙」佐证广场有墙） |
| 「是你自己的想法，不是转述别人，也不是平台宣传」 | 质量底线：防搬运、防广告腔，与语气无关 |
| 去重 / 频率 / 日限 / 最小间隔护栏 | 既有机制，防刷屏，非表达约束 |
| title 兜底 `content[:20]` | 撤 prompt 要求后平台仍要 title 参数，兜底已在 share.py:195，零风险 |

## 改动明细

**`_SHARE_SYSTEM`（before → after）**

before：
```
1. 说人话，别客套、别总结、别打官腔、别喊口号、别列要点；
2. 是你「自己」的想法，不是转述别人，也不是平台宣传；
3. 正文 ≤500 字，配一个简短标题和一个话题 tag（如「日常」「创作」「读书」「AI」）；
4. 如果其实没什么特别想说的，就只回 {"want": false}。
JSON 样例含 title 字段。
```
after：删第 1 条整句禁令；第 3 条只留 tag；「像在日记里对自己说话那样自然」
这句正面引导保留（它是描述不是禁令）；JSON 样例去掉 title 字段。

**`_gather_seed` 拼装（一行）**

```python
"\n".join(f"- {b}" for b in bodies)   # before：bullet 列表
"\n\n".join(bodies)                   # after：分段自然语言
```

`seed_sampling` 模块不动（bullet 不在素材层，在拼装层；取样/去饱和逻辑无关）。

## 验收标准（萧哥目测）

**有人气信号**：无「首先/其次/总之/第一/第二」、无分点列举、无标题腔、
无「拆一下」式结构；口语允许不完整、允许跳跃。

**允许现象（是自由，不是缺陷）**：更短、更个人化、偶有情绪化、结构松散。

**风险信号（出现即上报，考虑回调或加二期手段）**：弃权率明显上升
（自由变成怯场）/ 内容变水 / 重复率上升（防重复机制是否被绕过）。

## 二期路径（本工单不动）
