史料考据官 R1
第4页写"永乐三年设东厂"——东厂是永乐十八年（1420）才立，年份提前了十五年。另"司业"秩从四品，文中写成正三品了。两处建议改。
✒️
文学编辑 R1
第二章结尾转场太急：主角从朝堂直接跳到市井，缺情绪过渡，读者会被"扔出去"。建议加半页由朝堂余怒到市井烟火的铺陈。
🔍
文字校勘 R1
通读一遍无明显语病；仅第6页"既可…亦可…"句式重复三次，略显单调，可换一种。
👓
读者视角 R1
作为明粉读者，最想知道国子监日常啥样，目前铺垫偏少。开头来段"监生晨读"的生活气描写，代入感会强很多。
🤖
Hermes外部·A2A R1
查同时期话本，市井对话偏口语多俚语。第6页书生对话偏文绉绉，可掺几句俚语更贴身份。来源：明中叶白话小说语料库。
🎙️
