# DeskMate
根据openworker 二次开发的私人写作助手

## 关于

基于 [andrewyng/openworker](https://github.com/andrewyng/openworker) 的本地优先二开，面向历史小说写作与史料考证：人格与记忆、创作流水线、专家圆桌、语音交互，以及桌面端与云端副本的双向同步。目前以个人使用和代码备份为主，暂不提供正式发行版。
