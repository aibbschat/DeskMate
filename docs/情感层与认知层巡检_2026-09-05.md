## 二、访谈引擎：存在、接线，但已经死了

### 真实库证据

| 指标 | 值 |
|---|---|
| `interview_sessions` | 3 |
| `interview_qa` | 3（**全部集中在 2026-09-04 一次会话**） |
| `should_interview_now(cognitive)` | **False** |
| `should_interview_now(emotional)` | **False** |
| 全部 gap 状态 | 3 个 **全是 resolved**，`open_gaps() = 0` |

### 死因链

```
gap 是存量消耗品，答完即清零
   ↓
open_gaps() = 0
   ↓
should_interview_now 需 open_gaps >= 2（或单条 priority>=0.8）
   ↓
恒 False → 小桔再也不提问
   ↓
静默失败（无报错、无日志、用户只感觉"她不问了"）
```

### 再生机制为什么没救活它

`conflict_gap.py`（2026-09-04 落地的好奇心再生）**只扫日记**：

- 触发条件：新日记的文本命中「关怀偏好 / 回血方式」维度，**且极性与既有条目相反**
- `conflict_scan_processed_ids` 已处理 13 篇，剩下的都是旧日记
- 他日常日记多是创作记录与情绪抒发，很少主动聊"希望怎么被关怀"
- → **实际再生概率极低**，等于没接

**这是第二次踩同一个坑**（MEMORY 已记「访谈燃料=open gap，答完即枯竭」），
上次补的再生机制因为只吃日记，治标没治本。

### 一个自我纠错

巡检中我一度怀疑「回血方式」两条互相冲突：
- 日记推断（0.93）：靠**投入创作/史料**回血
- 他亲口说（0.60）：看影视剧、听音乐、**出去走走**

查完 `conflict_gap` 的极性词表确认：两条都命中 `solitude`（独处向），
**同极性不算冲突，不生成 gap 是正确行为**——是我判断错了，规则没错。

## 四、层层相连：断点在哪

```
                    他说的所有话
                         │
     ┌───────────────────┼───────────────────┐
     │                   │                   │
  日记 15 篇       learned_history 227 条    访谈 3 条
     │                   │                   │
     ▼                   ✗ 断                 ▼
┌─────────┐                            ┌──────────┐
│认知层    │                            │情感画像   │
│54 条     │◄────── ✗ 断 ──────────────│9 条      │
└────┬────┘                            └────┬─────┘
     │ gap                                   │ ✗ 断
     ▼                                       ▼
  open=0                              当日心情时间线
     │                                       │
     ▼                                       ▼
  访谈死了 ◄──── 无新素材 ────► 花园定色只反映写日记那天
```

**三处断裂，互相放大：**

1. **认知层只吃日记** → 画像薄 → 没有真冲突 → 生不出 gap
2. **gap=0** → 访谈不触发 → 没有新的自述素材进来
3. **访谈不回流时间线** → 他亲口说的只进画像不进当日 → 花园照旧只认日记

递进关系正如萧哥所说：**一层没做到位，每层都坏**。
认知层缺料 → 情感层没燃料 → 访谈静默死亡 → 意志层（成为我）更无从谈起。

227 条存量**不需要重新理解**，只需要：

1. 按 `ts` 增量幂等（记 processed ids，和 `diary_extract` 同一范式）
