## 0. 一句话现状

桌面壳（Tauri）先建窗口再 spawn Python sidecar（**随机端口**，8765 只是回退），前端 injected token 直连；Python 侧 `coworker/` 是通用 Agent 后端、`deskmate/` 是小桔领域层；云端 `xiaoju-*` systemd 单元处于停机保号，同步靠每小时窗口 + `SQLiteLease` 单写。**框架基本齐备，欠账集中在三处：部署清单漂移、人格单一源被旁路、读稿预算与问题粒度脱钩。**
