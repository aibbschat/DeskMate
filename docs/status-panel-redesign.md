# StatusPanel 重设计方案

## 一、当前问题诊断

### 1.1 信息架构混乱
**问题**：所有功能平铺堆砌，没有信息层次

当前排列顺序（从上到下）：
```
Header（名称+等级+情绪）
↓
当前状态
↓
成长进度条
↓
关系轨（3个进度条）
状态轨（3个进度条）
↓
连续对话横幅
↓
成就徽章（6个+展开）
↓
人格指纹雷达图
↓
技能熟练度列表
↓
成长时间线（5条）
↓
主动模式开关
↓
近期记忆（4条）
↓
了解度统计+记忆列表
↓
操作按钮（2个）
```

**问题分析**：
- 共 **11 个内容区块**，全部堆叠
- 没有主次之分，用户不知道先看什么
- 关键信息（等级、心情）被淹没在细节中
- 所有内容都需要滚动才能看完

### 1.2 视觉噪音过多
- 每个区块都有 emoji 前缀（💗🤝✨☀️⚡🏆🎭 等）
- 颜色系统混乱：6 种进度条颜色 + 4 种稀有度颜色 + 背景渐变
- 文字大小只有 3 种（10px/11px/12.5px），层次不清晰

### 1.3 交互逻辑不清
- 哪些元素可以点击？（成就？技能？记忆？）
- 哪些是只读展示？
- Hover 效果不一致（成就有 tooltip，其他没有）

### 1.4 空间利用率低
- 面板宽度 372px，但很多内容只用了左半部分
- 进度条区域可以两栏并排，但布局不够紧凑
- 成就徽章的 tooltip 位置不合理（向上弹出可能被裁切）

## 二、设计原则（参考优秀案例）

### 2.1 Finch 的设计哲学
**核心理念**：温和、非评判性、鼓励式反馈

**借鉴点**：
- 状态用**情绪图标+简短描述**，而非数字
- 进度用**柔和的渐变色**，不用高对比度
- 重要信息（心情、能量）用**大图标+大字体**
- 次要信息（历史、统计）**折叠或分页**

### 2.2 Habitica 的游戏化设计
**核心理念**：清晰的 RPG 风格，数据驱动

**借鉴点**：
- **HP/XP/MP 三大核心指标**在最顶部，一目了然
- 状态属性用**属性名+数值+进度条**的标准格式
- 成就系统独立页面，不在主面板堆砌
- 角色形象占视觉主导地位

### 2.3 原神角色面板设计
**核心理念**：信息分区明确，视觉锚点突出

**借鉴点**：
- **左侧大立绘**占 40% 宽度
- **右侧分栏**：基础属性、武器、圣遗物、天赋
- 每个分区有**明确的标题和边框**
- 关键数值（等级、生命值）用**特殊样式强调**

## 三、重设计方案

### 3.1 设计目标
1. **3 秒内抓住重点**：用户打开面板，3 秒内知道"它现在怎么样"
2. **信息分层清晰**：核心 → 重要 → 次要 → 详情
3. **减少认知负荷**：同一时间只展示 3-5 个信息块
4. **可探索性强**：次要信息折叠，鼓励点击探索

### 3.2 新信息架构（4 层）

```
┌─────────────────────────────────────────┐
│ Layer 1: 核心身份（固定，不滚动）        │
│ - 桌宠形象（Canvas 微型版）              │
│ - 名称 + 等级 + 阶段名                   │
│ - 当前情绪（一句话）                     │
│ - 连续对话天数（小徽章）                 │
└─────────────────────────────────────────┘
↓ 点击展开
┌─────────────────────────────────────────┐
│ Layer 2: 核心状态（默认展开，可折叠）    │
│ - 心情 + 活力（大图标 + 数值）           │
│ - 亲密度 + 信任度 + 默契度（3列网格）    │
│ - 成长进度条（简化版）                   │
└─────────────────────────────────────────┘
↓
┌─────────────────────────────────────────┐
│ Layer 3: 成就与个性（默认折叠）          │
│ - 成就概览（最近 3 个 + "查看全部"）     │
│ - 人格指纹（小尺寸雷达图）               │
└─────────────────────────────────────────┘
↓
┌─────────────────────────────────────────┐
│ Layer 4: 详情与操作（折叠，需点击）      │
│ - 技能熟练度                             │
│ - 记忆时间线                             │
│ - 了解度统计                             │
│ - 主动模式开关                           │
│ - 操作按钮                               │
└─────────────────────────────────────────┘
```

### 3.3 视觉设计规范

#### 字体层次
```
标题（区块标题）：11px, font-weight: 600, color: var(--ink)
数值（关键指标）：20px, font-weight: 700, color: var(--ink)
标签（属性名）：10px, font-weight: 400, color: var(--muted)
描述（辅助文字）：10.5px, font-weight: 400, color: var(--faint)
```

#### 颜色系统
```
核心指标（心情/活力）：
  - 高（>70%）：绿色系 #10b981
  - 中（40-70%）：黄色系 #f59e0b
  - 低（<40%）：红色系 #ef4444

关系指标（亲密度/信任/默契）：
  - 统一使用品牌色 #6366f1（紫色系）

进度条：
  - 填充：渐变色（起点色 → 终点色）
  - 背景：var(--line)，低对比度

稀有度（仅成就）：
  - 普通：灰色边框
  - 稀有：蓝色边框
  - 史诗：紫色边框
  - 传说：金色边框
```

#### 间距规范
```
区块间距：16px（gap-4）
元素间距：8px（gap-2）
内边距：12px（p-3）
圆角：8px（rounded-lg）
```

### 3.4 详细布局设计

#### Layer 1: 核心身份卡片
```
┌─────────────────────────────────────────┐
│ [Canvas 微型桌宠]   墨灵                 │
│   120x120px      Lv.3 · 墨童             │
│                   😊 活力满满             │
│                   📅 连续 12 天           │
└─────────────────────────────────────────┘
```

**设计要点**：
- 左侧放桌宠 Canvas 微型版（120x120px），增加情感连接
- 右侧用大字体显示等级和阶段名
- 情绪用 emoji + 4 字描述，不用进度条
- 连续天数用小徽章，不喧宾夺主

#### Layer 2: 核心状态面板
```
┌─────────────────────────────────────────┐
│  😊 心情        ⚡ 活力                  │
│  78%           55%                       │
│  ████████░     ██████░                   │
├─────────────────────────────────────────┤
│  💗 亲密度    🤝 信任度    ✨ 默契度     │
│   62%          30%         45%           │
│   ████         ██          ███           │
├─────────────────────────────────────────┤
│  ✨ 成长 Lv.3 → Lv.4                     │
│  ████████████████░░░░░  45/80 XP         │
│  再积累 35 点成长值即可升级               │
└─────────────────────────────────────────┘
```

**设计要点**：
- 心情和活力用**大号字体 + 进度条**，视觉权重最高
- 关系指标用**3 列网格**，节省空间
- 成长进度条放在最后，作为"下一步行动"的引导

#### Layer 3: 成就与个性（折叠面板）
```
┌─────────────────────────────────────────┐
│ ▶ 成就徽章 (4/15)                        │
│   👋初见 🤝老友 🎨造物者 💕亲密伙伴     │
│   [+11 更多...]                          │
├─────────────────────────────────────────┤
│ ▶ 人格指纹                               │
│   [小尺寸雷达图 80x80px]                 │
│   活力75 创意85 逻辑60 共情70             │
└─────────────────────────────────────────┘
```

**设计要点**：
- 默认折叠，点击标题展开
- 成就只显示最近 4 个已解锁 + "更多"按钮
- 人格指纹用小尺寸雷达图，不占太多空间
- 展开后显示详细信息

#### Layer 4: 详情与操作（折叠面板）
```
┌─────────────────────────────────────────┐
│ ▶ 技能熟练度 (3)                         │
│   [展开后显示技能列表]                   │
├─────────────────────────────────────────┤
│ ▶ 我们的记忆 (32)                        │
│   [展开后显示记忆时间线]                 │
├─────────────────────────────────────────┤
│ ▶ 关于你                                 │
│   了解度 32 | 偏好 12 | 习惯 8          │
│   [展开后显示详情]                       │
├─────────────────────────────────────────┤
│ 主动模式  [开关]                         │
├─────────────────────────────────────────┤
│ [📝 查看记忆]    [✏️ 文稿编校]           │
└─────────────────────────────────────────┘
```

**设计要点**：
- 所有内容默认折叠，减少初始视觉负荷
- 每个区块用 "▶" 图标表示可展开
- 操作按钮固定在底部，始终可见

## 四、交互设计

### 4.1 面板打开动画
```
初始状态：从桌宠位置飞出，缩放 0.8 → 1.0，透明度 0 → 1
时长：200ms
缓动：ease-out
```

### 4.2 折叠/展开动画
```
展开：高度从 0 → auto，透明度 0 → 1
收起：高度从 auto → 0，透明度 1 → 0
时长：150ms
缓动：ease-in-out
```

### 4.3 Hover 状态
```
可点击元素：
  - 背景色：var(--paper)
  - 光标：pointer
  - 过渡：background-color 100ms

成就徽章：
  - Hover 时显示 tooltip（从下方弹出，避免被顶部裁切）
  - 边框颜色加深 20%

进度条：
  - Hover 时显示精确数值 tooltip
```

### 4.4 点击反馈
```
折叠面板标题：
  - 点击时背景闪一下（active:var(--line)）
  - 箭头旋转 90°（▶ → ▼）

操作按钮：
  - 点击时缩放 0.95 → 1.0
  - 背景色加深 10%
```

## 六、技术实现要点

### 6.1 Canvas 微型桌宠
- 在 Layer 1 左侧嵌入 120x120px 的 Canvas
- 只渲染桌宠本体，不渲染粒子效果
- 跟随主桌宠的状态同步（情绪、等级）
- 通过 postMessage 或 ref 调用更新

### 6.2 折叠面板组件
- 使用 `<details>` + `<summary>` 或自定义实现
- 状态管理：`useState<boolean[]>` 记录每个区块的展开状态
- 动画：CSS transition 或 Framer Motion

### 6.3 成就 Tooltip
- 使用 `position: absolute` + `z-index: 10`
- 检测边界，自动调整方向（上方空间不足时向下弹出）
- 点击其他区域关闭 tooltip

### 6.4 数据懒加载
- Layer 4 的记忆列表、技能列表默认不渲染
- 展开时才 fetch 数据或渲染完整列表
- 减少初始渲染开销

## 十、成功指标

### 10.1 可用性指标
- 用户打开面板后 **3 秒内**能找到当前心情状态
- 用户能在 **5 秒内**找到成就系统入口
- 折叠面板的点击率达到 **30%+**（说明用户有探索欲）

### 10.2 视觉指标
- 面板整体视觉层次清晰，无"信息堆砌感"
- 关键信息（等级、心情）的视觉权重明显高于次要信息
- 颜色系统统一，无视觉噪音

### 10.3 性能指标
- 面板打开动画 **< 200ms**
- 折叠展开动画 **< 150ms**
- 初始渲染只渲染 Layer 1 + Layer 2（**< 100 个 DOM 节点**）
