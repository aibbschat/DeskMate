## 已知坑速查

- `safety-card` strings 漏检 = Tauri brotli 压缩导致的误报。
- `--install` 不能只看 exit code，必须查 PlistBuddy 版本号。
- WorkBuddy 沙箱会拦 vite 批量删 dist；脚本已预移走旧 dist，必要时清 shim 环境变量。
- `PATH` 必须含 `~/.cargo/bin`，否则 cargo metadata 挂。
- `VITE_*` token 禁止构建期烘焙；云端走 `runtime-config.json`。
- `.env.local` 对 build 也生效，禁止创建；只允许 `.env.development.local`。
- aarch64 `E0463 / mis-aligned LINKEDIT` 已由 vendor/ctor + `[profile.release] strip="none"` 固化，别改回。
