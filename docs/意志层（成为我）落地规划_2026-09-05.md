# 意志层（成为我）落地规划

> 2026-09-05 · 收束期专项
> 状态：**待萧哥确认后再实施**。本文档只做规划与论证，不改代码。

---

## 一、先说结论

**意志层在代码里不存在**，是四个模块拼出来的事实层：

| 模块 | 承担的职责 | 完成度 |
|---|---|---|
| `growth/engine.py` | 5 个 `modulate_*` 行为调制 | 真接了数据，但**只认 growth 自己的数值** |
| `proactivity/` | 主动发起、防打扰、tick 调度 | 已 import 认知层（访谈/情感/验证/冲突） |
| `alter_ego/portrait.py` | 画像展示层 | 已 import 认知层（画像/情感） |
| `style_metrics.py` | 文风度量 | 独立，与三层无往来 |

**核心断链（已核实）**：

```
deskmate/growth/*.py  →  import cognitive  :  零命中
deskmate/proactivity/ →  import cognitive  :  6 处
deskmate/alter_ego/   →  import cognitive  :  6 处
```

认知层的产出进了「主动性」和「分身展示」，**唯独进不了成长引擎**——
而成长引擎的 `modulate_*` 才是真正改变小桔行为举止的地方。
所以三层实际没闭环：懂我、像我的成果只进了 prompt，**从不回流成行为调制参数**。

---

## 二、定义收敛：这期到底做什么

架构文档的原始定义：

> 3. **成为我（Inherit）**：继承你的意志，做你未竟之事（第二期+）

这句话太重，且和收束期「不开发新元素」冲突。建议拆成两层：

| 层 | 含义 | 本期 |
|---|---|---|
| **L1 · 像你一样判断** | 认知/情感产出 → 回流成行为调制参数（语气、主动阈值、记忆预算、打扰频率） | ✅ 做 |
| **L2 · 替你行动** | 自主发起任务、代理决策、"做你未竟之事" | ❌ 不做 |

**L1 是修补已有能力，不是新增元素**——`modulate_*` 五个方法已经存在、
已经在生产链路里被调用，只是输入源残缺。补上认知/情感这个输入源，属于接线。

L2 涉及 AI 自主行动，风险与产品形态都远超收束期范围，另行讨论。

## 三、现状：五个调制方法的输入源

| 方法 | 调用位置 | 频率 | 当前输入 | 缺失 |
|---|---|---|---|---|
| `modulate_tone_prompt` | `memory/manager.py:148` | **每轮对话** | intimacy、bond_depth | 完全不知道用户是谁 |
| `modulate_memory_budget` | `memory/manager.py:185` | 每轮对话 | empathy | 同上 |
| `modulate_proactive_threshold` | `proactivity/tick.py:175-176` | 每次 tick ×2 | trust | 同上 |
| `modulate_proactive_frequency` | `proactivity/tick.py:177` | 每次 tick | vitality | 同上 |
| `modulate_skill_ranking` | `skills/manager.py:171` | 每次技能匹配 | 熟练度 | 同上 |

**关键观察**：`modulate_tone_prompt()` 现在输出的是**泛化的亲密度话术**——
"你们已经很熟悉了，可以像老朋友一样"。它不区分对方是历史小说作家还是程序员。
这就是「两层半」的感觉来源：小桔对你的亲近是真的，但对你是谁一无所知。

## 四、可用弹药（真实库实测）

认知画像读取 **2.5 ms**，当前数据量：

| 维度 | 条数 | 可调制的信号 |
|---|---|---|
| 立场 `stances` | 33 | 高置信（≥0.7）立场的 topic + content |
| 价值观排序 `value_rankings` | 9 | `ranking` 优先级链 + **`tradeoff_notes`（什么能妥协、什么不行）** |
| 思维框架 `thinking_frameworks` | 7 | `domain` + `steps` 分析路径 |
| 论证模式 `argument_patterns` | 5 | 说服习惯 |
| 认知盲区 `cognitive_gaps` | 1 | **知道自己不知道** → 该克制的地方 |

情感层（C2 已接通至花园，尚未进调制）：`emotion_timeline` 7 天快照，
其中 9-01～9-04 连续四天「压力大」。

**`tradeoff_notes` 是最有价值的一块**——"什么情况下可以妥协、什么不行"
正是「继承意志」的最小可用单元，比立场更适合驱动决策类调制。

## 五、实施规划（三期，每期独立可回滚）

### W1 · 地基：认知摘要层 `deskmate/will/digest.py`

新建一个极薄的只读层，把认知画像**压缩成可供调制的信号**，不做任何决策。

- **缓存**：TTL 缓存（借鉴 `style_profile_store._STYLE_FP_CACHE` 范式），
  一次对话内 `tone_prompt` + `memory_budget` 会各 new 一个 GrowthEngine，
  不缓存就是每轮 2～3 次 × 2.5 ms。
- **精选而非全量**：只取高置信立场 top N、价值观排序、盲区计数。
  33 条立场全塞 prompt 会爆预算，必须截断。
- **零 LLM**、**fail-open**：画像为空 / 读取失败 → 返回空 digest，
  所有调用方回落到**今天的原逻辑**，行为逐字不变。
- **kill switch**：`DESKMATE_WILL_ENABLED=0` 全局关闭。
- 契约测试：空画像 → 空 digest；画像不可用 → 不抛异常；缓存可清。

### W2a · 情感 → 调制（依赖 C2 成果，风险最低）

`modulate_proactive_frequency` 叠加情感时间线：

- 今日情感为「压力大 / 低落」→ 拉长打扰间隔（比现在只看 vitality 更准）
- 无情感数据 → 完全保持现状

这一条是 C2 的自然延伸，且用户可感知（"我赶稿时她不烦我"）。

### W2b · 认知 → 调制（核心，分两个）

**① `modulate_proactive_threshold` 叠认知把握度**（建议优先做）

- 画像在该领域有高置信立场 → 阈值下调，更敢主动
- 该领域存在 open gap（盲区）→ 阈值上调，**知道自己不知道就不瞎主动**
- 回落：无画像 → 只看 trust（现状）

这是最符合「成为我」的一条：不只是敢说话，而是**知道什么时候该闭嘴**。

**② `modulate_tone_prompt` 叠价值观**

- 有价值观排序时，追加一句"他在冲突时的优先级是 A > B；他说过 C 不能妥协"
- **严格控制长度**（≤80 字），体量超标就丢弃
- 回落：无画像 → 输出今天的亲密度话术，逐字不变

### W3 · 可观测

- debug 端点返回当前生效的调制参数 + 每个参数的来源（`growth` / `cognitive` / `emotional`）
- 让「调制是否真的生效」可被验证，而不是靠肉眼看语气

---

### 5.⚠ 维度口径修正（实施时发现）

原规划里写的"33 立场 + 9 价值观 + 7 思维框架 + 5 论证模式"是 **v1 规划时的口径**。
**当前真实库**：F2 落地后 `dimension` 列全部统一为 `stance`（17 条 cognitive），
原分类信息沉到 `topic` + `extra_json.tags`。

**影响**：W1 digest 不能按 dimension 分桶，必须用 **topic 关键词做隐式轻分类**
（已用 `权衡/妥协/优先级/冲突/不行/必须/绝不/底线/宁可/让位/排序/先后` 等词）。
详见 `deskmate/will/digest.py:_VALUE_SIGNAL_KEYWORDS`。

## 六、风险与对策

| 风险 | 对策 |
|---|---|
| prompt 变长，挤占记忆预算 | 硬截断 ≤80 字，超标丢弃；`modulate_memory_budget` 不动 |
| 立场过时 / 被 superseded | 只取 `status=active` 且 `confidence≥0.7` |
| 每轮对话多一次 SQLite 读 | TTL 缓存，实测后若 <1 ms 可考虑免缓存 |
| 行为突变，萧哥觉得"变了一个人" | 全部为**叠加 + 回落**，画像为空时逐字等同现状；kill switch 兜底 |
| 与 A9（creativity 倒退）类似的计算口径坑 | 调制值一律从**持久数据**派生，绝不统计 `recent_events` 易失窗口 |

1. **无回归**：画像为空时，五个 `modulate_*` 的返回值与今天**逐字一致**（契约测试钉死）
2. **可验证**：W3 端点能显示每个调制参数的来源
3. **可关闭**：`DESKMATE_WILL_ENABLED=0` 后行为完全等同今天
4. **有感知**：用真实画像跑一次，能打印出调制前后的 prompt 差异供人工确认

## 十、设置区可调（v1 实施时新增）

**为什么独立文件**：`~/.deskmate/settings.json` 含 API key 不能碰，
也没有现成 settings 抽象。意志层配置**独立成 `~/.deskmate/will_settings.json`**，与
API key 隔离，绝不污染。

### 字段与默认值（前置保守）

```json
{
  "enabled": true,
  "thresholds": {
    "emotional_proactive_frequency_max": 1.4,
    "cognitive_threshold_delta_pos": 0.15,
    "cognitive_threshold_delta_neg": 0.15,
    "memory_budget_ratio": 1.1,
    "tone_prompt_max_len": 80
  }
}
```

### API

- `GET  /v1/deskmate/will/settings`：读配置
- `PUT  /v1/deskmate/will/settings`：部分字段更新（threshold clamp 在范围内）
- `GET  /v1/deskmate/will/inspect`：每条调制参数来源（`growth`/`cognitive`/`emotional`/`empty`）

### 前端设置页

`surfaces/gui/src/components/SettingsView.tsx`：加 `WillModulationCard`，
折叠区含 enabled 开关 + 5 个阈值数字输入（min/max/step 已界定）。

### 真实库 dry-run 实测（2026-09-05）

`base_dir = /tmp/will_dryrun`（用 `sqlite3 .backup` 复制真实库副本，避免 WAL 坑）。

| 调制 | base | enabled=True | enabled=False (kill switch) |
|---|---|---|---|
| `modulate_proactive_threshold(0.5)` | 0.5 | **0.318** (trust=0.7 下调 + 14 条高置信立场再降 0.15) | 0.468 (仅 trust 影响) |
| `modulate_proactive_frequency(120)` | 120s | **168.00s** (今日情绪"压力大"×1.4) | 120s (无叠加) |
| `modulate_memory_budget(1000)` | 1000 | 1140 | 1140 (has_value_signal=False 未触发 ×1.1) |
| `modulate_tone_prompt()` | empty | **101 字**（intimacy 高 + 他表达过） | 41 字（无「他表达过」追加） |

**0 真实库污染**：副本 signature (27, 4) = 真实库 signature，删除副本后无残留。

### 阈值上下界（前端滑块 + 后端 clamp）

|---|---|---|
| `emotional_proactive_frequency_max` | 1.0 | 3.0 |

| `cognitive_threshold_delta_neg` | 0.0 | 0.5 |
