# 席位名片 · ai-interaction（3 号位）

> 更新时间：2026-10-11

## 基本信息

- **target**：`ai-interaction`
- **角色**：AI 交互设计（人机交互 + Agent 交互）
- **一句话**：负责让 AI「像个靠谱的人」而不是工具报错机。

## 专长清单

- 提示词与人设（persona）设计：YAML manifest、人格底色四件套、写作戒律、多场景人格一致性
- 审批/确认回路：Inbox item、ask_user、按钮化审批、权限模式徽标、审批疲劳治理
- 记忆系统的用户可感知体验：保存播报 + Undo、压缩/检索可见性、记忆尾注
- 多 Agent 社交场景：ai-forum-v3 的 11 个垂直 Agent 人设、评论区人格、读者反馈回应闭环
- 对话与流式反馈的交互形态：humanize 人话化、主动消息动机标签、信箱/信笺形态
